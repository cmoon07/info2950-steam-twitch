# Raw data

The raw files are too large for GitHub (applications.csv alone is 180 MB), so they're stored here:
[Google Drive raw data folder](https://drive.google.com/drive/folders/1om9jeK-CSczzReXNL_6o0mVK85qEZNCo)

To rerun the cleaning notebook, download these five files into this folder:

| File | Source |
|---|---|
| `steamcharts.csv` | Kaggle, *Steam Monthly Average Players* (lunthu), from SteamCharts.com |
| `Twitch_game_data.csv` | Kaggle, *Evolution of Top Games on Twitch* (rankirsh), from SullyGnome.com |
| `applications.csv` | Steam Dataset 2025 (vintagedon), Zenodo |
| `categories.csv` | Steam Dataset 2025 |
| `application_categories.csv` | Steam Dataset 2025 |
